# Wordle Clone (CSC 321 HW2)

Wordle clone built from the freeCodeCamp tutorial, plus three new features.

## Running it

```
npm install live-server
npx live-server build
```

## New features

1. **Time Attack**: choose "Time attack (60s)" in the Mode dropdown to solve the word in 60 seconds. Each new green letter adds 5 seconds.
2. **Theme Weeks**: the Theme dropdown switches between Classic, Food, Tech, Movies and Geography. Each theme has its own word list and look.
3. **Coins, streaks and power-ups**: wins earn coins and build win and daily streaks, all saved in localStorage. Coins buy "Reveal a letter" (15) or "Remove 2 letters" (10).
